# Northstar SQL Challenge — Simplified Prototype

This is a static website containing the first three-minute challenge of the Marketing Analytics AI Challenge.

## Run locally

Open Terminal in this folder and run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

Upload this entire folder to Netlify Drop. No build command, backend, database, or API key is required.

## Files to edit

- `index.html` — wording and page structure
- `styles.css` — visual design
- `data.js` — table data
- `app.js` — SQL engine, answer checking, and hints
